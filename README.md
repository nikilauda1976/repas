# Repas de la maison

Les menus de la semaine, la liste de courses et les recettes en PDF.

- `semaines.json` : les menus de chaque semaine (un identifiant de recette par soir, du lundi au dimanche, `null` pour un soir libre) et le nombre de personnes.
- `recettes.json` : toutes les recettes (ingrédients pour 6 portions, matériel, étapes).
- `index.html` : le site.

Pour changer un menu, modifiez `semaines.json` sur GitHub : le site se met à jour en une minute environ.
