# Repas de la maison

Les menus de la maison : choisissez vos menus (riches en protéines, légers ou végétariens), réglez le foyer, et la liste de courses se fait toute seule.

Le site tient dans un seul fichier, `index.html`. Les menus cochés, les favoris et les réglages sont gardés sur chaque appareil.

« Mes recettes » (`perso.js`) : chaque famille ajoute ses propres recettes, écrites à la main, prises en photo ou importées (PDF, Word, texte). La lecture se fait dans le navigateur (Tesseract.js, pdf.js, mammoth), puis la recette est rangée par type et mise au format des autres. Les comptes famille (`compte.js`) les partagent entre les appareils.
